# Draft Logging Rule

Always save all generated drafts (both text and image artifacts) directly to the `logs/` directory.

### Naming Convention
- **Format**: `<topic>_#<iteration>.<ext>`
- **No Date / Time**: Do NOT include day, month, year, or time in the filename.
- **Topic**: Descriptive snake_case name for the post/topic (e.g. `ai_vs_traditional_agencies`, `it_sector_ai_hit`).
- **Iteration Tag**: Track the revision count with `#1`, `#2`, `#3`, etc. for each round of edits or updates.
- **Media Artifacts**: Follow the same convention with descriptive labels (e.g., `<topic>_visual_#1.jpg`).
