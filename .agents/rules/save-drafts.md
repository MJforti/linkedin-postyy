# Draft Logging Rule

Always save all generated drafts (both text and image artifacts) directly to the `logs/` directory.

### Naming Convention
- **Format**: `DD-MM-YYYY_<post_name>_#<iteration>.<ext>`
- **Date**: Day, month, year only (e.g. `06-10-2026`). Do NOT include the time.
- **Iteration Tag**: Track the revision count with `#1`, `#2`, `#3`, etc. for each round of edits or updates.
- **Media Artifacts**: Follow the same convention with descriptive labels (e.g., `DD-MM-YYYY_<post_name>_visual_#1.jpg`).
